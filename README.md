# عالم روري ♡

موقع هدية تفاعلي لرويدا، باللغة العربية واللهجة الليبية، بألوان وردية وبيضاء هادئة.

## الأشياء التفاعلية
- زر يفتح رسالة شخصية.
- أزرار لكل بطاقة تعرض رسالة مختلفة.
- اختيار المزاج يغير رسالة المواساة.
- أظرف تفاعلية تحتوي كلمات حلوة.
- مطر قلوب متحركة.
- حقل كتابة محلي، لا يرسل النص إلى أي مكان.
- زر نسخ الرسالة.

## النشر على GitHub Pages
1. افتح https://github.com وسجل الدخول.
2. أنشئ مستودعًا جديدًا باسم `roida-gift`.
3. ارفع `index.html` إلى المستودع عبر Add file → Upload files، ثم Commit changes.
4. افتح Settings → Pages.
5. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/(root)` واضغط Save.
6. انتظر بضع دقائق وافتح الرابط الذي يظهر في صفحة Pages.
7. اختبر الموقع على هاتفك ثم أرسل الرابط إلى رويدا.

كل التفاعلات تعمل داخل المتصفح. حقل الرسالة لا يحفظ البيانات على الإنترنت ولا يرسلها لأي شخص.
